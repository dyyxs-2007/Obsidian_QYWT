# 本周学习内容

1. 学习了Masonry约束的链式结构的写法和对UIScrollView以及其子视图进行masonry约束的方法
2. 复习了关于cell创建部分的知识
3. 结合基础控件，导航栈，工具栏与界面传值，自定义cell等做了一个任务清单demo，实现了多界面下的任务添加，任务删除，实时更新状态
4. 以UITabBar控制器与导航栈为容器，写了一个结合界面传值、警告栏、BarButton的工具箱demo，巩固了对这些控制器的理解和掌握
5. 完成了一个集成基础控件的个人资料显示demo
6. 学习了UICollectionView的UICollectionViewFlowLayout创建，顺便复习了cell的注册，复用流程

# 本周遇到的问题

1. 在ScrollView中使用TextField的时候，点击屏幕收回键盘的代码失效
2. 在约束UIScrollView的时候，添加上了一个图片却无法显示
3. 在学习UIScrollView的masonry约束的时候不清楚为什么底部必须要进行约束(已解决)
4. 在使用UITextField配合navigation的pop方法的时候，在弹出键盘的情况下直接使用按钮pop视图会导致闪退原因应该是当前视图被销毁，但键盘仍在与其交互，访问空指针报错
5. 在自定义cell的时候，initWithStyle方法不会自动初始化属性，需要单独创建，并且没搞清楚在哪里为其赋值(已解决)
