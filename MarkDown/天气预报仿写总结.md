## PageVC

按理说，点击cell要进入天气详情页面

- 首先我们定清载体，天气详情卡要做到左右翻动，需要使用到一个叫做`UIPageViewController`的UI，它是一个VC容器，管理作为page的各VC

既然选择UIPageViewController搭载天气页面，就需要把这个UIPageViewController先展示出来

这里常规的情况有两种方式，一个是通过`presentViewController`弹出来，一个是通过Navigation`push`进去，但这两种方法最终都没采用，为了仿原生的动画，我最后选择使用一种搭建父子VC的方式：

1. 点击cell时创建`UIPageViewController`然后把它的view约束在rootVC的View中，这样就可以直接展示，并且这样的形式对于动画来说比较好做，这里是点击cell的代理

```obj
- (void)setupPageVC:(NSInteger)index {
    self.pageViewController = [[UIPageViewController alloc] initWithTransitionStyle:UIPageViewControllerTransitionStyleScroll navigationOrientation:UIPageViewControllerNavigationOrientationHorizontal options:nil];
    WeatherModel *currModel = self.section[index];
    DetailViewController *detail = [[DetailViewController alloc] init];
    [detail configWithModel:currModel];
    detail.dismissDetail = ^{
        [self removePageVC];
    };
    [self.pageViewController setViewControllers:@[detail] direction:UIPageViewControllerNavigationDirectionForward animated:NO completion:nil];
    self.pageViewController.dataSource = self;
    self.pageViewController.delegate = self;
    [self addChildViewController:self.pageViewController];
    [self.rootView addSubview:self.pageViewController.view];
    [self.pageViewController didMoveToParentViewController:self];
    
    self.bottom = [[BottomCardView alloc] init];
    __weak typeof(self) weakSelf = self;
    self.bottom.tappedDisMiss = ^{
        [weakSelf removePageVC];
    };
    [self.bottom configWithIndex:index total:self.section.count];
    [self.pageViewController.view addSubview:self.bottom];
    [self.bottom mas_makeConstraints:^(MASConstraintMaker *make) {
        make.bottom.left.right.equalTo(self.pageViewController.view);
    }];
}
```

- 首先我这里是把DetailVC作为真正天气界面的底层加在PageViewController上面，这是为了让DetailVC专心处理返回的手势，这样真正的天气界面就只需要进行一个UI的展示

2. 退出时，当DetailVC响应了对应的退出手势，这里会调用一下下面这个方法，解除我们刚刚建立的`UIPageViewController`与rootVC的父子关系，视图自然不再现实

### 防抖

`SearchController`有一个监听搜索行输入的代理，每当调用这个方法时，我们再调用`self.searchResult`我们自己写的的更新方法，把用户输入的内容传进去

```objc
- (void)updateSearchResultsForSearchController:(UISearchController *)searchController {
    NSString *currStr = searchController.searchBar.text;
    if (currStr.length != 0) {
        [self.searchResult updataWithString:currStr];
    }
}
```

紧接着我们需要实现一个防抖的功能，这是因为用户如果持续输入，总不能输入完一个单词，进行了十几次网络申请，这样返回的结果不断刷新界面体验感很差，所以我们需要一个延迟检测，假如用户输入后0.3s左右没有新的输入，再进行网络申请，否则直接取消上次的申请任务

这里我使用了`[self performSelector: withObject: afterDelay:]`方法，这个方法的大致作用是设置一个delay延迟后运行的任务，对象是self，方法名用选择器传入，中间这个是如果方法需要参数的传参途径，同时还需要一个`[NSObject cancelPreviousPerformRequestsWithTarget: selector:@selector object:];`方法配合取消上一次的任务

```objc
- (void)updataWithString:(NSString *)keyWord {
    self.currID++;
    self.resultView.nullCard.hidden = YES;
    
    [self.task cancel];
    [NSObject cancelPreviousPerformRequestsWithTarget:self selector:@selector(work:) object:nil];
    
    [self performSelector:@selector(work:) withObject:keyWord afterDelay:0.2];
}

- (void)work:(NSString *)keyWord {
    [self.citys removeAllObjects];
    [self.resultView.tableView reloadData];
    __weak typeof(self) weakSelf = self;
    
    NSInteger judgeID = self.currID;
    NSString *Coded = [keyWord stringByAddingPercentEncodingWithAllowedCharacters:[NSCharacterSet URLQueryAllowedCharacterSet]];
    NSString *http = [NSString stringWithFormat:@"https://geocoding-api.open-meteo.com/v1/search?name=%@&count=10&language=zh&format=json&countryCode=CN", Coded];
    self.task = [[NetWorkManager sharedNetWork] GET:http completion:^(NSArray * _Nonnull citys, NSError * _Nonnull error) {
        if (error) {
            if (error.code == NSURLErrorCancelled) {
            }
            NSLog(@"网络请求失败");
            return;
        }
        __strong typeof(weakSelf) self = weakSelf;
        if (!self) {
            return;
        }
        if (self.currID != judgeID) {
            return;
        }
        self.citys = [citys mutableCopy];
        [self.resultView.tableView reloadData];
        if (citys.count == 0) {
            self.resultView.nullCard.hidden = NO;
        } else {
            self.resultView.nullCard.hidden = YES;
        }
    }];
}
```

- 下面这个方法是网络申请的方法，请注意，调用自己写的GET方法的时候需要把Task拿回来，因为输入更新后，假如已经发出去的网络申请事实上也已经过时了，返回的结果其实是上一次输入的内容，这时候就得取消掉，就可以直接调用task的cancel方法，否则逻辑会很麻烦

**接下来我们思考异步回调的问题**

假如发送两次申请，第一次的网络延迟较大，500ms，第二次为100ms，那么第二次申请完毕后，最先返回的也许会是第二次的结果，因为延迟更低速度更快，那么界面会先刷新成第二次的结果，符合预期，但是再过一会会，第一次的申请信息也回来了，就会直接把第二次的结果覆盖掉

我给出的解决办法是提前设置一个计数器，self持有一个，block持有一个，如果输入行更新，就把self持有的数字++，由于block封存的特性，假如它持有的和self持有的数值不同，就说明进行了第二次搜索，这时候直接return，防止UI刷新，也就达成了我们的目的，这也是上面代码中judgeID和currID的作用

## 毛玻璃

- 因为想到每个cell中都要使用毛玻璃，如果在每个UI界面都创建再布局，工程量很大，我们尝试封装起来复用

我们先定义一个GlassCard类，并且在.h文件中暴露出一个外界可以访问的属性用于UI在其上布局

```objc
#import "GlassCard.h"
#import <Masonry/Masonry.h>

@interface GlassCard ()
@property (nonatomic, strong, readwrite) UIView *contentView;
@property (nonatomic, strong) UIView *overLay;
@property (nonatomic, strong) UIVisualEffectView *effectView;

@end

@implementation GlassCard

- (instancetype)initWithFrame:(CGRect)frame
{
    self = [super initWithFrame:frame];
    if (self) {
        [self setupUI];
    }
    return self;
}

- (void)setupUI {
    [self setupCard];
    [self setupMasonry];
}

- (void)setupCard {
    self.layer.cornerRadius = 24;
    self.clipsToBounds = YES;
    self.layer.borderColor = [UIColor colorWithWhite:1 alpha:0.08].CGColor;
    self.layer.borderWidth = 0.5;
    
    UIBlurEffect *effect = [UIBlurEffect effectWithStyle:UIBlurEffectStyleRegular];
    self.effectView = [[UIVisualEffectView alloc] initWithEffect:effect];
    self.effectView.alpha = 0.6;
    [self addSubview:self.effectView];
    
    self.overLay = [[UIView alloc] init];
    self.overLay.backgroundColor = [UIColor colorWithWhite:1 alpha:0.08];
    [self addSubview:self.overLay];
    
    self.contentView = [[UIView alloc] init];
    [self addSubview:self.contentView];
}

- (void)setupMasonry {
    [self.effectView mas_makeConstraints:^(MASConstraintMaker *make) {
        make.edges.equalTo(self);
    }];
    [self.overLay mas_makeConstraints:^(MASConstraintMaker *make) {
        make.edges.equalTo(self);
    }];
    [self.contentView mas_makeConstraints:^(MASConstraintMaker *make) {
        make.edges.equalTo(self).insets(UIEdgeInsetsMake(9, 14, 9, 14));
    }];
}
```

请看以上代码，contentView在.h文件中额外设置了一个readonly，外界不可修改，在m文件中，依次创建毛玻璃，遮罩层，还有最终的外界访问的画布，遮罩层`overlay`起到了一个提亮度更反光的玻璃效果作用，

- 剩余的cell内部UI布局就是正常约束，在此不过多赘述

# 网络申请单例

```objc
#import "NetWorkManager.h"
#import "HourlyWeatherModel.h"
#import "DailyWeatherModel.h"

@implementation NetWorkManager
+ (instancetype)sharedNetWork {
    static NetWorkManager *instance;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        instance = [[super allocWithZone:NULL] init];
    });
    return instance;
}

+ (instancetype)allocWithZone:(struct _NSZone *)zone {
    return [self sharedNetWork];
}

- (NSURLSessionTask *)GET:(NSString *)http completion:(void (^)(NSArray *, NSError * _Nonnull))completion {
    NSURL *url = [NSURL URLWithString:http];
    NSURLRequest *request = [NSURLRequest requestWithURL:url];
    NSURLSession *session = [NSURLSession sharedSession];
    NSURLSessionTask *task = [session dataTaskWithRequest:request completionHandler:^(NSData * _Nullable data, NSURLResponse * _Nullable response, NSError * _Nullable error) {
        if (error) {
            NSLog(@"网络请求失败");
            dispatch_async(dispatch_get_main_queue(), ^{
                completion(nil, error);
            });
            return;
        }
        NSError *jsonError;
        NSMutableDictionary *rootDict = [NSJSONSerialization JSONObjectWithData:data options:0 error:&jsonError];
        if (jsonError) {
            dispatch_async(dispatch_get_main_queue(), ^{
                completion(nil, jsonError);
            });
            return;
        }
        NSMutableArray *arr = rootDict[@"results"];
        NSMutableArray *result = [NSMutableArray array];
        for (NSDictionary *dict in arr) {
            CityModel *model = [[CityModel alloc] init];
            model.name = dict[@"admin2"];
            model.admin1 = dict[@"admin1"];
            model.latitude = dict[@"latitude"];
            model.longitude = dict[@"longitude"];
            model.ID = [dict[@"id"] intValue];
            [result addObject:model];
        }
        dispatch_async(dispatch_get_main_queue(), ^{
            completion(result, error);
        });
    }];
    [task resume];
    return task;
}

- (void)GET:(NSString *)http Weather:(void (^)(WeatherModel *, NSError * _Nonnull))completion {
    NSURL *url = [NSURL URLWithString:http];
    NSURLRequest *request = [NSURLRequest requestWithURL:url];

}
```
