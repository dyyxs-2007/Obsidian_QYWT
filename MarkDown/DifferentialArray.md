# 前缀和与差分数组的概念：
## <font color="red">差分(differential)</font>：
### 概念：
-  差分数组指的是对于一个已经给定的数组，我们人为地构造出第二个数组
- 这个新数组满足以下几个条件：
1. 第一个元素与原数组第一个元素相同
2. **从第二个元素起**，每一个元素值为原数组的**当前下标**对应值减去**前一个下标**对应值

用表达式表示就是这样
> 假设orig[]为原数组，diff[]为差分数组
> diff[0] = orig[0]
> diff[i] = orig[i] - orig[i - 1]  （i > 0）

### 举例：
orig[] = {1, 4, 6, 3, 2, 1, 7}
diff[] = {1, 3, 2, -3, -1, -1, 6}
- 这里diff[0] = orig[0], diff[1] = orig[1] - orig[0],以此类推
## <font color="red">前缀和(prefix sum)</font>：
### 概念：
- 前缀和指的也是对于一个给定的数组，人为的构造出第二个数组
- 这个新的数组的每个下标的元素，储存着从原数组同下标的**前面所有元素之和**

用表达式表达如下：
> 假设orig[]为原数组，prefix[]为前缀和数组
> prefix[i] = orig[0] + ...... + orig[i]

### 举例：
orig[] = {1, 4, 6, 3, 2, 1, 7}
prefix[] = {1, 5, 11, 14, 16, 17, 24}
- 这里prefix[0] = orig[0], prefix[1] = orig[0]+orig[1],以此类推

- 差分由于求出的是数组间的差值，所以经常被用于**区间共同加减的问题**上，可以很便捷的在差分数组的区间**前后端**操作，再求前缀和，后面我们会以例题形式讲解

# 前缀和与差分的关系
## 两者的相互转换
- 前缀和和差分是互逆的关系，也就是说，**对一个数组求差分，再对得到的差分数组求前缀和又回到了原数组**，反过来，**先求前缀和再差分也能回到原数组**，我们不妨对这个性质进行验证：
> 原数组orig[ ] = {1, 4, 6, 3, 2, 1, 7}
> 对原数组求前缀和 prefix[ ] = {1, 5, 11, 14, 16, 17, 24}
> 对prefix求差分 diff[ ] = {1, 4, 6, 3, 2, 1, 7}

> 原数组orig[ ] = {1, 4, 6, 3, 2, 1, 7}
> 对原数组求差分 diff[ ] = {1, 3, 2, -3, -1, -1, 6}
> 对diff求前缀和 prefix[ ] = {1, 4, 6, 3, 2, 1, 7}

- 由上可见，无论先差分还是先求前缀和都能回到原数组，所以求差分和求前缀和的操作是<u>互逆的</u>

## 与数学微积分之间的联系
- 对于要用到差分解决的问题中基本都要涉及前缀和，这是为什么呢？因为差分求的是相邻数组元素间的变化量，就像是数学中的导数，差分的过程就是对原数组**求导**
- 而当我们对差分数组进行了一些改变的时候，为了反映回原数组，我们要对差分数组求前缀和，这个本质是对差分数组的**积分**，只是这个“函数”是离散点罢了
- 所以对一个“函数的导数操作完”，要对其积分回去得到最终答案，<u>求导只是为了借用导数的一些特殊性质</u>
# 核心应用与实战场景
## 前缀和：
### 区间和问题：
- [区间和](https://kamacoder.com/problempage.php?pid=1070)
- 问题描述：
> 给定一个整数数组 Array，请计算该数组在每个指定区间内元素的总和

- 解题思路：
1. 利用前缀和的思想，求出原数组对应的前缀和数组prefix[]
2. 如果想要求[i, j]内的区间和，只需要用前缀和相减的办法
3. 由于前缀和数组储存的是对应下标的原数组前面所有数的和，所以**prefix[j] 代表原数组[0, j]的所有元素和**，**prefix[i]代表原数组[0, i]的所有元素和**，两者相减，最后**加上被多减去的orig[i]就可以了**
## 差分：
### 区间加法问题：
- [区间加法]()
- 问题描述：
> 假设你有一个长度为 n 的数组，初始情况下所有的数字均为 0，你将会被给出 k​​​​​​​ 个更新的操作
> 其中，每个操作会被表示为一个三元组：[startIndex, endIndex, inc]，你需要将子数组 A[startIndex ... endIndex]（包括 startIndex 和 endIndex）增加 inc。 
> 请你返回 k 次操作后的数组。

- 例如：
```c
示例:
输入: length = 5, updates = [[1,3,2],[2,4,3],[0,2,-2]]
输出: [-2,0,3,5,3]

解释:
初始状态:
[0,0,0,0,0]
进行了操作 [1,3,2] 后的状态:
[0,2,2,2,0]
进行了操作 [2,4,3] 后的状态:
[0,2,5,5,3]
进行了操作 [0,2,-2] 后的状态:
[-2,0,3,5,3]
```
- 解题思路(以例题为例)
1. 先求出它的差分数组，此时差分数组记录的是相邻元素间的变化趋势
    diff[] = {0，0，0，0，0}
> 由于在对一个区间的所有数同时进行加减的时候，区间内相邻的数的差没变，所以在区间内的差分数组的值应该不变
> 那么这个同时加减改变的只有差分数组区间端点的值了
> 由于差分数组记录的是orig[i] 与orig[i - 1]之间的差，所以要想做到区间[i, j]内加减， 改变的是diff[i]和diff[j + 1]，并且，同时加时，diff[i]应该加相同值，diff[j + 1]应该减去相同值
> **换成区间同时减的话就相当于同时加一个负数**
- 可能你会想如果j + 1超出引索了怎么办，那就说明**j已经指向了区间的最后一个元素**，这其实也就不需要对diff[j + 1]减什么了，因为我们知道原数组的j之后就没有元素了，**不需要关心是否把加过的东西减回来**
- 这里不理解没关系，在做题的时候慢慢就会懂得
2. 根据要求的区间下标i, j, 以及目标是加还是减，第一次需要对[1, 3]中的数同时+2，按照上面的分析，对diff[1]+2,对diff[4]-2, 
3. 此时diff[]变为了{0，2，0，0，-2}
4. 第二次对[2, 4]中同时加3，同样过程，diff变为{0，2，3，0，-2}
5. 第三次对[0, 2]中同时加（-2），diff变为{-2，2，3，2，-2}
6. 对最后操作完的diff求出前缀和：prefix{-2, 0, 3, 5, 3}得到答案

# 二维差分
- 二维差分的本质就是多次的进行一维差分，用于解决原数组为二维数组的情况，方法与应用与一维差分类似，这里不过多赘述了
# 总结：
- 前缀和与差分数组都是以创建新数组的形式将原数组的一些性质单独拿出来，以达到更快的解决问题的办法
- 应用的场景多为求区间变化方面，思路都是**先求差分，再对差分数组的区间端点进行操作**，免去遍历多次的困扰，最后再利用前缀和转换为原数组
