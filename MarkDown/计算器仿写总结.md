##  label设计

我们知道，官方的计算器中输入长串数字一是可以随着输入长度变换字体大小，二是可以在超出屏幕后滑动，第一个比较好实现，那就是在config更新方法里面写一个判断条件更改UI，第二个比较难，实现方法如下

- 使用一个scollView套住label，并且让label凭自己的text长度约束自己的大小，再约束在scrollView里面，这样就实现了长内容的滑动

我们看到，我只对scrollView进行了约束，这是因为无论怎么滑动，总得有一个固定的窗口，所以scrollView一定是定死的，而可以改变的是scrollView里面的contentsize大小和label在里面的位置，而每次更新内容的时候，需要重新对这个scrollView的contentsize进行约束，所以就有了layoutDisplay这个方法，我们进入其中看看

3. 把label放上去，这一步就是基于scrollview进行的，使用CGSizeMake的话，就要从左和上开始，所以起点就是本身contentwidth的全长，减去label的真实长，有人这里会问，为什么不直接放在scrollView的左上呢，这是因为如果label长度比较短，那不就约束到左边去了吗
4. 最后是调整初始偏移量，让文字的最右边和scrollView的最右侧对齐，这里偏移到刚好剩下一个窗口的长度就行，并且为了避免负数，和0取一个最大值

# 计算逻辑与分工

写下计算部分的代码以前，我们要先明确计算的方式，在计算器中一般采用的都是逆波兰表达式，也就是后缀计算式，而我们平时采用的都是中缀表达式，如`1+1`是中缀表达式，为了计算，就要先转化为后缀表达式：`11+`这样的好处就是计算机不用顾虑运算优先级而可以采用一个流程循环的处理一整个式子，这一点在后面计算逻辑会详细解释

但是我们需要看到的输入以及处理的输入却是适合人类的中缀表达式，所以就需要一个中缀转后缀的过程

- 并且从刚刚那个例子也可以看出来，如果想要中缀转后缀，就需要把每一个数，和运算符分隔开然后进行重组，这用string肯定是做不到的，事实上，数组是最适合做这个工作的，我们可以这样组织数据：把每一个数字，运算符都放进一个名为token的数组中，如

```objc
token = @[
    @"1",
  	@"+",
		@"1"
];
//伪代码
```

- 然后把token数组进行内部重组，最后计算出token数组的所有内容

下面的目标就很清晰了：

1. 处理输入，把点击的内容从Controller传入CalculatorEngine
2. CalculatorEngine处理输入，把陆续输入的字符或数组拼接成token数组
3. 点击=时把token数组从CalculatorEngine传入Parser
4. Parser把token数组从中缀转为后缀，计算后缀
5. 把计算结果传回controller

## CalculatorEngine

`- (NSString *)input:(NSString *)input;`这是该类仅向外提供的唯一一个接口

在处理输入前，我们得想清楚几个问题：

1. 输入数字时我们不能直接把用户的输入放进token数组，因为有可能后面还要加数字，比如输入一个2，不能直接放进token因为用户可能想输入22
2. 不能连续输入两个加号，还有其他的禁止输入的情况如不能直接输入右括号等等还有很多情况，
3. 返回的字符串需要像用户展示当前输入

针对第一个问题，我们的解决办法是，维护一个临时的string，用于存放数字，当确认数字输入完了，直接放入token

- 比如这样；
  1. 输入2	token：{ }  currentNumber : "2"
  2. 输入2.        token: { }.  currentNumber : "22"
  3. 输入+.        token : { "22", "+"}.  currentNumber : ""

针对第二个问题，我们需要用枚举维护一个状态，什么状态？前一个输入的是什么，比如前一个输入的是+，那么我在下一个输入的时候就不能输入=，也不能输入小数点

```objc
- (NSString *)appendStrings {
    for (NSInteger i = 0; i < self.token.count; i++) {
        NSMutableString *str = self.token[i];
        if (!([str isEqualToString:@"+"] || [str isEqualToString:@"-"] || [str isEqualToString:@"×"] || [str isEqualToString:@"÷"] || [str isEqualToString:@"("] || [str isEqualToString:@")"])) {
            self.token[i] = [NSString stringWithFormat:@"%g", [str doubleValue]];
        }
    }
    NSMutableString *str = [NSMutableString string];
    for (NSString *nums in self.token) {
        [str appendString:nums];
    }
    [str appendString:self.currentNumber];
    return str;
}
```

这个方法可以让每次调用input的具体内容时可以无脑调用然后返回目前存着的所有东西，那个for循环是为了消去前导0以及其他无意义内容

## Parser

```objc
#import "Parser.h"

@implementation Parser

- (NSString *)outPutWithInput:(NSArray *)outPut {
    double result = [self meddleToBehind:[self formateNegative:outPut]];
    if (result == 0) {
        return @"0";
    }
    if (result == INFINITY || result == -INFINITY) {
        return @"未定义";
    }
    if ([@"nan" isEqualToString:[NSString stringWithFormat:@"%g", result]]) {
        return @"错误";
    }
    return [NSString stringWithFormat:@"%g", result];
}

- (NSArray *)formateNegative:(NSArray *)input {
    NSMutableArray *token = [input mutableCopy];
    for (int i = 0; i < token.count; i++) {
        NSString *str = token[i];
        if (i == 0) {
            if ([str isEqualToString:@"-"]) {
                token[i] = @"_";
            }
            continue;
        }
        NSString *prev = token[i - 1];
        if ([str isEqualToString:@"-"] && ( [prev isEqualToString:@"+"] || [prev isEqualToString:@"-"] || [prev isEqualToString:@"×"] || [prev isEqualToString:@"÷"] || [prev isEqualToString:@"("])) {
            token[i] = @"_";
        }
    }
    return token;
}

- (double)meddleToBehind:(NSArray *)input {
    NSMutableArray *output = [NSMutableArray array];
    NSMutableArray *stack = [NSMutableArray array];
    
    for (NSString *token in input) {
        if ([self isNumber:token]) {
            [output addObject:token];
            continue;
        }
        if ([token isEqualToString:@"("]) {
            [stack addObject:token];
            continue;
        }
        if ([token isEqualToString:@")"]) {
            NSString *item = stack.lastObject;
            while (![item isEqualToString:@"("]) {
                [stack removeLastObject];
                [output addObject:item];
                item = stack.lastObject;
            }
            [stack removeLastObject];
            continue;
        }
        NSString *last = stack.lastObject;
        if ([last isEqualToString:@"("]) {
            [stack addObject:token];
            continue;
        }
        if (stack.count == 0) {
            [stack addObject:token];
            continue;
        }
        NSInteger myself = [self numberOfOperator:token];
        NSInteger your = [self numberOfOperator:last];
        if (myself > your) {
            [stack addObject:token];
        } else {
            while (stack.count > 0 && myself <= your) {
                [output addObject:stack.lastObject];
                [stack removeLastObject];
                NSString *la = stack.lastObject;
                if ([la isEqualToString:@"("]) {
                    break;
                }
                your = [self numberOfOperator:la];
            }
            [stack addObject:token];
        }
    }
    while (stack.count > 0) {
        [output addObject:stack.lastObject];
        [stack removeLastObject];
    }
    return [self answerFromFix:output];
}


- (BOOL)isNumber:(NSString *)str {
    if ([str isEqualToString:@"+"] || [str isEqualToString:@"-"] || [str isEqualToString:@"×"] || [str isEqualToString:@"÷"] || [str isEqualToString:@"("] || [str isEqualToString:@")"] || [str isEqualToString:@"_"]) {
        return NO;
    }
    return YES;
}

- (NSInteger)numberOfOperator:(NSString *)operator {
    if ([operator isEqualToString:@"+"] || [operator isEqualToString:@"-"]) {
        return 1;
    }
    if ([operator isEqualToString:@"×"] || [operator isEqualToString:@"÷"]) {
        return 2;
    }
    if ([operator isEqualToString:@"_"]) {
        return 3;
    }
    return 0;
}


- (double)answerFromFix:(NSArray *)input {
    NSMutableArray *stack = [NSMutableArray array];
    for (NSString *str in input) {
        if ([self isNumber:str]) {
            CGFloat number = [str doubleValue];
            [stack addObject:@(number)];
            continue;
        }
        double result = [stack.lastObject doubleValue];
        [stack removeLastObject];
        if ([str isEqualToString:@"+"]) {
            result += [stack.lastObject doubleValue];
        } else if ([str isEqualToString:@"-"]) {
            result = [stack.lastObject doubleValue] - result;
        } else if ([str isEqualToString:@"×"]) {
            result *= [stack.lastObject doubleValue];
        } else if ([str isEqualToString:@"÷"]) {
            result = [stack.lastObject doubleValue] / result;
        } else {
            result = -1 * result;
            [stack addObject:@(result)];
            continue;
        }
        [stack removeLastObject];
        [stack addObject:@(result)];
    }
    return [stack.lastObject doubleValue];
}

@end

```

- 这里就是Parser的全部内容，首先获取token数组，接着转后缀，转后缀的流程由以下几个规则建立
- 转后缀的过程需要用到两个数组，一个是结果数组，一个是运算符栈，我们需要遍历token数组，遇到数字直接放进结果数组，如果是运算符：
- 如果运算符栈空，直接压栈，如果token遍历到的运算符优先级大于运算符栈顶运算符的优先级，就直接压进运算符栈，否则一直弹运算符栈，把弹出来的内容放进结果数组，直到满足条件把当前运算符压运算符栈
- 在这之前要先处理一下负号的情况，把负号用其他字符替换，比如_或者#，最后计算遇到这个直接取相反数就行
- 如果是括号，遇到左括号直接把左括号压进运算符栈，等遇到右括号的时候一直弹运算符栈，把弹出来的结果放进结果数组，直到遇到左括号然后把左括号扔掉
- 关于符号优先级可以看我的`- (NSInteger)numberOfOperator:(NSString *)operator`方法

经过上面的步骤就产生了后缀表达式，那么后缀表达式如何计算呢，这里还是要用到栈

1. 按顺序遍历后缀表达式，遇到数字直接入栈，遇到符号(非负号)就拿出来俩数字进行计算，遇到负号就取相反数，把计算出来的结果放回到栈里，最后当遍历完后缀表达式的时候，栈顶就是最终结果

经过上面的流程就可以得到最终的计算结果，然后传回给CalculatorEngine，再由CalculatorEngine传回给Controller再给rootView更新UI即可
