# 归并排序核心思想
## 分治的策略
### 分治的概念：
-  所谓分治，就是将一个问题一分为二或一分为多，再研究这些被分割开的子问题，如果能分别解决这些子问题，最终再合理的合并在一起，就可以以点代面解决复杂问题
- 归并排序就是采取的这样的策略
### 为什么在排序中想到分治？
- 用我们自然的想法去思考：是很多个无序的数好排序还是给你一个数好排序？
> 答案显然是单个数， 因为一个1或者一个7，它们天然就已经排好了顺序，不存在其他的排序可能

- 所以如果我们把一串无序的数组分割成一个个孤立的数字，那么我们就相当于把每个孤立的数排了序，剩下的只有把这些有序的数组合并回去了
### 数组的归并排序用到的分治策略
1. 数组的优势是数组可以通过下标进行快速索引，所以我们对一个数组进行分治的时候，先定义左右端点为初始数组左右端点，接下来只需要找到一个<font color=pink>中间下标</font>，从这里断开
- 如a[<font color=blue>1, 4, 2<font color=red>, 5, 3, 6</font></font>] 断开之后就会是：<font color=blue>a1[1, 4, 2]</font> 和 <font color=red>a2[5, 3, 6]</font>
2. 显然的，一次分割并不够我们预期达到的单个数字，继续在左右循环下去吗？
3. 事实上，我们这里采用的方法是递归地进行左右切割，当第一次切割完成后，保留<font color=pink>中间下标</font>
   1. 第一行递归，将<font color=pink>中间下标</font>作为**右端点**递归函数，我们不关心它进行的具体操作，只需要知道传入它之后，在这层递归中会把<font color=blue>a1[1, 4, 2]</font>进行第二次分割，得到1这个单数字和[4，2]再进行下一行
   2. 第二行递归，将<font color=pink>中间下标</font>作为**左端点**递归函数，同样的，他会将<font color=red>a2[5, 3, 6]</font>进行再次分割
4. 设置递归终止条件为当左右端点相等（即只剩一个元素时）退出递归
### 链表的归并排序用到的分治策略
> 与数组的分治策略相似，但由于链表不能通过下标直接访问中间值
> 所以我们需要利用一个快指针，一次跳过两个节点，以及一个慢指针，一次跳过一个节点
> 让两个指针同时从head开始移动，直到快指针到链表尾部，慢指针恰好到链表正中间

1. 由于链表是由每个节点的上一个节点的指针串连起来的，所以我们在分治的时候需要直接将***已经分开的不同区域***中的指针“掐断”，用示例展示就是这样的：
- 如a[<font color=blue>1-> 4-> 2<font color=red>-> 5-> 3-> 6</font></font>] 断开之后就会是：<font color=blue>a1[1-> 4-> 2]</font> 和 <font color=red>a2[5-> 3-> 6]</font>
- 注意这里的**a1的2后面还指着a2的5**，如果不将他断开，以后我们在合并的时候就会因为找不到子链表的尾部而无法合并，这一点在后面的代码实现中也可以看到
## 分治得到的结果
1. 我们先分析递归到最底层的结果：
- 由于我们刚刚分析了，当左右端点相等，即当前区间有且仅有一个数的时候返回，
- 这时候返回到了上一层递归，这里的当前区间不只有刚刚返回回来的单个数字，还有另一边同样被切割为单个数字的数组
-  这时候两边都已经有序，可以进行合并再返回
2. 我们再分析一般的结果，这时候应该是递归从底层返回到一半
- 由于从底层返回到当前的递归中，每一次都将两边各自有序的数组合并为一个有序的大数组返回，与上一层的另一边数组再合并
- 所以当前的分治结果就是从左端点到<font color=pink>中间下标</font>有序的数组 - 和 - 从<font color=pink>中间下标</font>到右端点的另一个有序的数组
- 此时我们将它合并为一个有序的整个数组返回即可
## 分治后的归并（合并）
> 想象你两只手里各有一个按顺序排列的扑克牌，第一摞是1， 4， 6
> 第二摞是2， 7， 9
> 你该怎样得到一个按顺序排列的一摞牌？
> 当然是先比较两摞牌的第一张，谁小先拿出来
> 再在剩下的两摞牌中比较第一张，谁小拿出来放结果数组的下面
> 重复这样的过程，就能将两个各自有序的数组合并为一整个有序的数组
- 我们要解决的问题是，将当前层函数中各自有序的<font color=blue>左区间</font>和<font color=red>右区间</font>合并为一整个有序的区间
- 仿照上面的结局问题的思路：
1. 我们设置两个指针（int类型，并不是真的指针）分别指向左边区间第一个数和右区间的第一个数, 指向左边的为<font color=blue>left</font>,右边的为<font color=red>right</font>
2. 定义i指针 = <font color=blue>left</font>， 用来在临时数组里储存值
3. 通过循环比较两个指针对应数的大小，并将目标值放入临时数组的i，同时将i和放入值的下标加1

## 分治过程
- 注意无论分治还是归并都采用同样的区间形式，我们这里使用**左闭右闭**区间[ ]
- 如果决定采用某个区间形式，就要始终维护它的逻辑成立，**即一个端点值不能被包含两次**，反映在代码中就是递归时的右部分<font color=blue>左端点</font>为middle + 1还是middle
```c
void mergeSort(int *nums, int left, int right, int *temp) {
    //对递归底层情况进行判断，如果只有一个元素了，就返回
    if (left == right) {
        return;
    }
    int middle = left + (right - left) / 2;
    //这里是找区间中点，为了防止right + left造成数组溢出，采用以上形式
    mergeSort(nums, left, middle, temp);
    mergeSort(nums, middle + 1, right, temp);
    //为闭区间，所以在中点右边要+1作为左端点
    ......
    //其他部分
}
```
- 经过此番操作，接下来运行的代码就会从最底层的单个数字的情况开始处理
## 归并过程
```c
void mergeSort(int *nums, int left, int right, int *temp) {
    //分治部分
    ......
    //作为额外指针，控制把左右区间中目标值拷贝进temp数组里
    int i = left;
    int begin1 = left, end1 = middle;
    int begin2 = middle + 1, end2 = right;
    //以上两行是为了确定循环范围，不至于超出索引
    //进入循环
    while (begin1 <= end1 && begin2 <= end2) {//只要有一方到头就退出
        if (begin1 <= end1 && nums[begin1] < nums[begin2]) {
            temp[i] = nums[begin1];//将小的放前面
            i++;//由于此时temp已经放进去了一个数，直接指向下一个
            begin1++;//nums[begin1]已经被放入了，将begin1也增加1
        } else {
            temp[i] = nums[begin2];
            i++;
            begin2++;
        }
    }
    //由于可能只有左边或者右边到尽头了，另一边还剩下一些数，所以需要单独判断
    while (begin1 <= end1) {
        temp[i] = nums[begin1];
        i++;
        begin1++;
    }
    while (begin2 <= end2) {
        temp[i] = nums[begin2];
        i++;
        begin2++;
    }
    ......
    //剩下拷贝过程
}
```
## 拷贝过程

```c
void mergeSort(int *nums, int left, int right, int *temp) {

    //拷贝过程
    for (int j = left; j <= right; j++) {

```
- 这一步的目的就是将temp中储存的临时结果拷贝回nums中，**由于temp我们用的是[left, right]段**，所以拷贝回去对其他部分的数没有任何影响

## 最终代码
```c
void mergeSort(int *nums, int left, int right, int *temp) {
    if (left == right) {
        return;
    }
    int middle = left + (right - left) / 2;
    mergeSort(nums, left, middle, temp);
    mergeSort(nums, middle + 1, right, temp);
    int i = left;
    int begin1 = left, end1 = middle;
    int begin2 = middle + 1, end2 = right;
    while (begin1 <= end1 && begin2 <= end2) {
        if (begin1 <= end1 && nums[begin1] < nums[begin2]) {
            temp[i] = nums[begin1];
            i++;
            begin1++;
        } else {
            temp[i] = nums[begin2];
            i++;
            begin2++;
        }
    }
    while (begin1 <= end1) {
        temp[i] = nums[begin1];
        i++;
        begin1++;
    }
    while (begin2 <= end2) {
        temp[i] = nums[begin2];
        i++;
        begin2++;
    }
    for (int j = left; j <= right; j++) {
        nums[j] = temp[j];
    }
}
```
# 链表归并排序的一般代码
## 参数与返回值
1. 由于链表需要我们返回一个头节点，所以它的返回值需要是一个ListNode类型（假设我们构造的结构体/类名为ListNode）
> 这里以c++为例，构造ListNode
```cpp
class ListNode {
public:
	ListNode(int x) {
		next = NULL;
		val = x;
	}
	ListNode(void) {
		next = NULL;
		val = 0;
	}
	int val;
	ListNode* next;
};
```
- 学c语言的同学也不要着急划走，接下来的内容基本上都是基于c语言写的，可以放心观看
2. 我们还需要传入一个链表的第一个节点

所以最终的链表归并排序主函数就是：
```c
 ListNode* mergeSort(ListNode*head) {
    ......
 }
```
## 递归终止条件：
1. 当链表头为空的时候，是不是说明链表没有节点，直接返回空就行
2. 当链表中只有一个元素的时候，说明链表已经有序，此时返回这个节点
- 综合以上两点，我们只需要判断当满足这两种条件中的任意一个就返回传入的head节点即可
```c
ListNode* mergeSort(ListNode*head) {
    if (NULL == head || NULL == head->next) {
	return head;
    ......
}
 }
```
- 这里思路也是和数组一样，一个节点的时候默认有序直接返回
> 刚刚提到的切割指针在这里也体现出来了，因为如果不设指针为空，这里就不能正常返回了
## 分治过程
- 按照先前的讲述，链表的分治使用了双指针
```c
ListNode* mergeSort(ListNode*head) {
    if (NULL == head || NULL == head->next) {
	return head;//终止条件
    //定义快慢指针
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast->next != NULL && fast->next->next != NULL) {
    	fast = fast->next->next;//快指针一次走两步
	    slow = slow->next;
    }
    //*关键*，临时定义一个指针保存这slow下一个的值，作为右侧区间的开始
    ListNode* temp = slow->next;
    //此处切割，让slow的下一个指针为NULL
    slow->next = NULL;

    ......
 }
```
- 最后两步比较关键，就是切割slow和slow的next
- 因为我们要将slow的前面看作<font color=blue>左区间</font>分治处理，将右边看作<font color=red>右区间</font>，这时候我们的确需要保存slow的下一个值作为<font color=red>右区间</font>的开端
- 如果让slow->next为NULL，那么递归之后在处理单个区间的时候，**判断head->next为NULL的时候就会失效**， 因为它的next并不为空， 哪怕它**逻辑上**已经是单个数字了，程序不会思考，**只会机械的判断next**
## 归并过程
- 链表的归并过程可以用递归来解决，代码量相较于数组少了不少
- 但是既然有递归，我们为了不和本函数递归冲突，要新开一个函数专门处理归并
```c
ListNode* merge(ListNode* s1, ListNode* s2) {
    //单独判断s1和s2是否同时为NULL，此时说明都到头了
	if (NULL == s1 && NULL == s2) {
		return NULL;
	} else if (NULL == s1 && NULL != s2) {
		return s2;
	} else if (NULL != s1 && NULL == s2) {
		return s1;
	}//一旦一个到头，可以直接在后面跟上不为空的索引，
	if (s1->val > s2->val) {//比较，让结果小的存住，把它的后面再和另一个递归，最终得到归并好的链表返回
		s2->next = merge(s1, s2->next);
		return s2;
	} else {
		s1->next = merge(s1->next, s2);
		return s1;
	}
}

 ListNode* mergeSort(ListNode*head) {
	......//已讲过程
    //为了后续归并，保存索引着排序好链表的头节点
	ListNode* left = mergeSort(head);
	ListNode* right = mergeSort(temp);
//当递归一直返回到第一层调用时，对这两个已经有序的链表归并再返回即可
	return merge(left, right);
}
```

## 完整代码
```cpp
class ListNode {
public:
	ListNode(int x) {
		next = NULL;
		val = x;
	}
	ListNode(void) {
		next = NULL;
		val = 0;
	}
	int val;
	ListNode* next;
};

void insertNode(ListNode* dummyhead, int val) {
	ListNode* temp = new ListNode(val);
	temp->next = dummyhead->next;
	dummyhead->next = temp;
}
ListNode* merge(ListNode* s1, ListNode* s2) {
	if (NULL == s1 && NULL == s2) {
		return NULL;
	} else if (NULL == s1 && NULL != s2) {
		return s2;
	} else if (NULL != s1 && NULL == s2) {
		return s1;
	}
	if (s1->val > s2->val) {
		s2->next = merge(s1, s2->next);
		return s2;
	} else {
		s1->next = merge(s1->next, s2);
		return s1;
	}
}
 ListNode* mergeSort(ListNode*head) {
	if (NULL == head || NULL == head->next) {
		return head;
	}
	ListNode* slow = head;
	ListNode* fast = head;
	while (fast->next != NULL && fast->next->next != NULL) {
		fast = fast->next->next;
		slow = slow->next;
	}
	ListNode* temp = slow->next;
	slow->next = NULL;
	ListNode* left = mergeSort(head);
	ListNode* right = mergeSort(temp);
	return merge(left, right);
}
```

# 小结
- 归并排序利用分治的思想将无序的排列拆解为一个个有序的排列再重新组装，保证了算法的高效性，是一种使用率高，效率高也十分重要的排序，将这种思想在链表上也是十分契合，是一种高效的链表排序方式
